# Research workflow

Use the user's RTK shell conventions. Keep manuscript sources, supplied journal templates, and private experimental notes in the designated external journal workspace.

- Plan. Use research-literature-evidence and experimental-design to define the question, provenance, independent experimental unit, baseline, and evaluation budget.
- Run. Use reproducible-dynamics-experiments and the project a2rl-manuscript-evidence skill to preserve raw data, seeds, settings and source revisions.
- Validate. Use statistical-analysis and scientific-visualization. Report uncertainty, failures, censoring, and whether an outcome is offline or closed loop.
- Write. Use scientific-writing, citation-management and journal-template-workflow. Preserve the supplied style and map claims to sources, data, tables or code. Send all generated LaTeX PDFs, PDF figures and build files to the journal workspace's `paper-pdf/` directory. Use the manuscript's build script or its latexmk configuration.
- Review. Use peer-review for authorized local review. Keep working drafts and reviewer material private. Obtain explicit authorization before submission or external sharing.

Load only skills relevant to the current task. Preserve the supplied class, options and preamble. Treat local simulator qualifications and physical validation as separate evidence.
